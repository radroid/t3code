Loops

A loop keeps a thread working while you are away, and collects what it needs from you in one place.

Let threads run as loops
When this is off, nothing fires and no thread can be armed. Loops that are already armed stand down — they keep their budget and their deadline, and resume when you switch this back on. Nothing is disarmed and nothing is stopped.

What a loop may do unattended

Let the model pace itself
Claude schedules its own wake-ups and is good at it within about half an hour. T3 reads what it scheduled and stands by while a wake is pending inside the run's deadline. Always on in phase 1 — the per-thread kill switch an earlier draft proposed was dropped (PLAN §3), so the row is shown fixed rather than live.
Check in when the model's own wake doesn't land
A self-paced wake lives in the provider process, so a restart or a stopped session loses it with no trace. This is the backstop: T3 records what was scheduled and covers it if nothing happens.
Keep going through a usage limit
Hands the wake to auto-resume and spends no check-in while held. Turning this off ends the loop at the limit instead.
These two rows are the whole relationship between the two schedulers. The model paces itself well inside its range — under about 30 minutes, before the session reaper's idle threshold. The hour cap is ScheduleWakeup's alone; CronCreate writes the same table with an unbounded cron expression, which is why T3 stands down only for a wake inside the run's own deadline. What the model cannot do is survive a restart: the cron table is in-process (cron_durable is still false), so a lost wake leaves no record it ever existed. T3's job is that gap, not the pacing.

How you find out

Push when a loop needs you
A question or approval it cannot get past. Uses the notifications you already set up.
Push when a loop stops
Finished, out of budget, or gave up. Says which — they are not the same thing.
Show loop check-ins in the transcript
Leaves a breadcrumb each time the loop restarts a thread, so a run is auditable after the fact.
